# Keystone Health To-do List

A small, dependency-free to-do application that stores tasks in the browser's `localStorage`.

## Run it

Open `todo.html` directly in a modern browser, or serve the repository with any static web server and visit `/javascript/todo.html`.

## Features

- Add, complete, and delete tasks
- Filter by all, active, or completed
- Clear all completed tasks at once
- Persist tasks across reloads using browser local storage
- Responsive layout and accessible labels/status messages

Tasks stay in the current browser profile on the current device; they are not synced to an account or server. Clearing browser site data removes them.
